# 声调实验记录（2026-11-25）

## 1. 这次要回答的问题

文本层（ASR 转写 + 拼音对齐）能抓到“增、漏、声母、韵母”，但抓不到“字没变、调读错”。
声调能不能靠 F0 自动判？判到什么程度？能不能直接进诊断、自动报错？

## 2. 数据与方法

- 数据：`s01_S01…S25` 共 25 条，16 kHz 单声道，人工听辨真值（`tone_truth.json`）。
  其中 S21–S25 是故意把三声读成四声，用来测“错读能不能抓到”。
- 文本层：faster-whisper small → 汉字 → pypinyin → 加权 DP（现有 `diagnosis.py`）。
- 声学层：whisper 词时间戳 → 按字数均分到字 → parselmouth 取 F0（75–400 Hz）→
  以本段录音浊音中位 F0 为零点换半音 → 起点/终点/峰值/谷值/升降幅/峰谷位置 → 规则判调。
- 代码路径与线上一致：`backend/app/services/{asr_backends,prosody,tone,tone_diagnosis}.py`。

## 3. 结果

### 3.1 文本层

| 指标 | 结果 |
|---|---|
| 5 条故意声调错中被报出 | **1/5**（买→卖 那条；其余 ASR 输出“合适/下日/很好/五个学生”，字都变了） |
| 25 条中误报 tone | 1 条（正常样本“雾”） |

### 3.2 F0 声学层

| 口径 | 结果 |
|---|---|
| 能判出调的样本 | 15/25（10 条无有效 F0 或字未对齐） |
| 判对 | **4/15（27%）**，按全部 25 条算是 4/25 |
| 参考：全猜四声 | 12/25（48%） |
| 置信度 ≥0.8 时 | 报出的条目里对的比例约 20% |
| 置信度 ≥0.9 时 | 报出的条目里对的比例为 0 |

逐条结果见 [声调实验-25条结果.md](声调实验-25条结果.md)。

### 3.3 对照：diagnosis-engine 旧路径

同一批 25 条，用 Paraformer 字级时间戳 + 旧版 F0 特征，最好成绩是 **9/25（36%）**，
8 个特征做留一法分类上限 44%，仍低于“全猜四声”的 48%。换切分方式（能量、音素分组、词时间戳）
都停在 7–9/25。

## 4. 为什么判不准

1. **句末半三声**：这批目标字大多在句末，三声实际读成 21（低降），声学形状和四声 51 高度重叠。
   这是语言事实，不是阈值能修的。
2. **倍频跳变**：F0 追踪偶尔跳到 2 倍频，出现“+8 半音”这种物理上不可能的起点/终点。
3. **切分误差**：whisper 词时间戳按字数均分，遇到 2 字词会把边界切在音节中间；
   字级时间戳（Paraformer）也有半音节误差。
4. **样本太少**：25 条里一声 2 条、二声 3 条，任何阈值都会过拟合，不能报“准确率”。

## 5. 结论与接入决定

**声调暂时不能自动报错。** 当前实现：

- 文本层原有的 `tone` 错误照常输出（例如 ASR 把“买”听成“卖”），不改变现有行为；
- F0 结果作为**证据**保留，默认不计算、不返回，避免给系统灌噪声；
- 需要做人工复核时，用环境变量打开：

```powershell
$env:TONE_EVIDENCE="1"      # 返回逐字 tone_evidence，不产生错误
$env:TONE_REPORT="strict"   # 额外允许“高置信”声调错（条件极严，25 条上 0 条触发）
```

返回字段示例（`tokens[i].tone_evidence`）：

```json
{"expected":"shui3","detected":"3","confidence":0.72,"reason":"先降后升",
 "start_ms":1920,"end_ms":2340,"contour_st":[-0.04,0.4,-0.94,3.74,8.08]}
```

**默认关闭的理由**：实测高置信区间精确率为 0–20%，打开后学生会看到大量假阳性，
比不报更糟。等有了隔离读法数据、把 3/4 声二分类做到 ≥80% 且精确率 ≥90%，再默认打开。

## 6. 如果要把声调真正做出来

按优先级：

1. **隔离读法补数据**（约 30 分钟）：10 个字单独读、字间停 0.5 s，2 人 × 3 遍，约 20–60 条。
   切分变简单后先验证“F0 到底能不能分开三/四声”。
2. **音素级强制对齐**：用已微调的 wav2vec2 音素模型（开发集 PER 6.7%）替代词时间戳，
   拿到音节/韵母边界，再做整条曲线特征（5 点归一化、二次拟合、时长、嘎裂声）。
3. **换模型**：句末半三声单靠 F0 无解，需要带声调标签的声学模型或商用发音评估 API；
   后者涉及录音出网、费用和授权，需先确认。
4. **另留测试集**：校准集和测试集不能混，至少 150 条、3 位以上说话人，才谈“准确率”。

## 7. 复现

```powershell
# 在 01_学生端/当前开发 下，使用已装 faster-whisper / parselmouth 的 Python
python backend/tools/tone_experiment.py `
  --audio-dir D:\大创\新的大创\diagnosis-engine\audio `
  --truth D:\大创\新的大创\diagnosis-engine\config\tone_truth.json `
  --pool D:\大创\新的大创\diagnosis-engine\config\tone_pool.csv `
  --out 声调实验-25条结果.md
```

音频和真值不在仓库内（`.gitignore` 排除音频）；换机器时把 `--audio-dir/--truth/--pool` 指到本地数据即可。
脚本没有音频会直接报错，不会用合成数据代替。
