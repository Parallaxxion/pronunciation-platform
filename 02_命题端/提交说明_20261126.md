## 一、启动方法

### 1.1 依赖

Python 3.11 以上。仓库未提供 `requirements.txt`，按 `docs/后端启动说明.md` 安装：

```powershell
$env:PYTHONUTF8 = "1"
python -m pip install fastapi uvicorn pypinyin
```

本次实际运行版本：Python 3.13、FastAPI 0.165.0、Uvicorn 0.54.0、pypinyin 0.55.0。版本未锁定，属已知缺口。

### 1.2 初始化数据库并启动后端

在 `02_命题端/当前开发` 目录执行：

```powershell
$env:PYTHONUTF8 = "1"
python backend/init_db.py --reset
python backend/import_bank.py
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
```

- 服务信息：<http://127.0.0.1:8001/>
- 接口文档：<http://127.0.0.1:8001/docs>
- 数据库路径默认 `backend/bank.db`，可用环境变量 `BANK_DB` 指向其他文件。

`backend/import_bank.py` 默认导入一级题库；其他等级的导入方式见 `docs/接口说明初稿.md` 与各等级 `banks/levelN/final.json`。

### 1.3 打开命题页面

另开终端：

```powershell
python -m http.server 8080 --directory frontend
```

打开 <http://127.0.0.1:8080/>。页面默认请求 `http://127.0.0.1:8001`，可用 `window.PROPOSITION_API_BASE` 覆盖。

**页面接通范围要区分清楚**：命题流水线、等级切换、题目列表、校验、统计、发布、抽题预览调用真实接口；页面里的学生、教师、管理演示区和“题目管理（增删改查）”仍使用 `frontend/data.js` 的预置数据，刷新后不会保存，不能当作已接通。

### 1.4 运行接口测试

```powershell
$env:PYTHONUTF8 = "1"
python backend/test_api.py          # 自动拉起独立测试库，端口 8017
python backend/test_levels.py       # 九级识别与空题库契约，端口 8018
```

## 四、尚未接通的地方（缺少的接口/字段）

### 4.1 题目管理（要求 1）

- 缺 `POST /api/questions`（新增）、`PUT /api/questions/{qid}`（编辑）、`DELETE /api/questions/{qid}`（删除）。
- 缺批量导入接口；目前只能命令行运行 `backend/import_bank.py`。
- 页面“题目管理”使用 `data.js` 预置数据，新增/删除不会写入数据库。
- 缺依赖锁定文件 `requirements.txt`、环境变量模板和前端启动脚本。

### 4.2 录音详情与偏误（要求 2）

命题端不保存录音和诊断结果，以下接口/字段均不在本仓库：

- `GET /api/admin/recordings?speaker_id=&question_id=&level=&status=&deleted=`，返回 `recording_id`、`speaker_id`、`question_id`、`take_no`、`recorded_at`、`question_snapshot`。
- `GET /api/admin/recordings/{id}/audio?variant=wav|original`，支持 Range 回放。
- `GET /api/admin/recordings/{id}/diagnosis`，返回 `diagnosis_available` 与 `status`（pending/processing/completed/failed）。
- 偏误字段：`tone`、`substitution`、`omission` 使用 `char_index`；`insertion` 使用 `boundary_index`；同字多类偏误数组；标点不计入 `char_index`。
- 缺“暂无结果”与失败原因的稳定字段约定。

以上应由学生端（管理员授权接口）和管理端提供，命题端只提供题目快照与 `rec_count`。

### 4.3 统计与导出（要求 3）

- 缺 `GET /api/admin/statistics`：采集人数（`registered_user_total`）、各等级/题目录音量、覆盖与缺口。
- 缺 `GET /api/admin/export`：音频、JSONL/CSV 清单、题目快照、诊断标注、SHA-256 清单的 ZIP。
- 缺导出校验脚本（如 `verify_export.py`）。
- 现有 `scripts/stats.py` 只统计题目文本、字表、语法点和题库结构，不含真实录音和音频文件。
- `PUT /api/v1/integration/coverage` 目前只保存快照并按版本去重，**尚未把覆盖计数写回题库 `rec_count`**。

### 4.4 权限、审计与异常（要求 4）

- 无鉴权：所有接口可直接访问，无 Bearer/服务令牌、无 admin/viewer 角色、无 401/403。
- 无审计：没有 `actions`、`history`、操作者、操作前后内容和撤销。
- 无并发保护：修改/发布没有 `expected_version`，旧版本不会返回 409。
- 无幂等：写接口没有 `Idempotency-Key`；仅录音计数按 `recording_id` 去重、覆盖快照按版本去重。
- CORS 为 `allow_origins=["*"]`，只适合本机联调，不能直接公网部署。

### 4.5 测试缺口（要求 5）

- 无命题页面的浏览器/设备测试记录；现有证据以接口脚本为主。
- 无权限不足、登录过期、并发修改、网络中断/超时的测试。
- `test_levels.py` 使用只导入一级题库的隔离库，报告里“二至七级 pending”是测试夹具状态，不代表正式题库未完成；正式题库文件已包含二至七级。
- `test_pipeline_levels.py` 使用每级两道占位题验证契约，不验证正式题库质量。
