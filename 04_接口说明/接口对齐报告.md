# 三端接口对齐报告

核对日期为2026年11月18日，版本见05_相关材料/来源与核验/source-snapshots.json。已完成的是源码接口核对、公共适配实现及样例验证；真实跨端身份、音频读取和写操作尚需各组共同接入。

## 已发现的差异和处理

| 项目 | 当前差异 | 本次处理 | 仍需完成 |
|---|---|---|---|
| 题目列表 | 命题API返回`{total,items}`；其前端读取`data.questions` | 适配器以items为主，同时支持旧数组和questions；提供最小补丁 | 命题组在本组分支合并补丁 |
| 题目来源 | 学生端当前本地抽题，命题端提供random/recommend | 明确命题服务为已发布题目来源，提供只读拉取脚本 | 学生组接入后仍须建立练习记录；保留题目快照 |
| 拼音 | 带调符号与数字声调并存 | 计算统一为小写TONE3，ü/v/u:归一为v；页面保留display_py | 算法输入调用适配，不能整句拼音按空格猜逐字对应 |
| 题目版本 | 两端尚无统一不可变版本约定 | 保留`question_version=null`，另算content_revision摘要 | 命题组提供正式版本；学生录音保留提交时快照 |
| 偏误格式 | 字符err、字间gap与管理端errors数组不同 | 转成tone/substitution/omission/insertion；done映射completed | 在真实数据接入处调用；上游多音节增读需完整保留 |
| 索引 | 原管理原型按整段文本字符展示，真实题目含标点 | 共同tokens只包含发音汉字；另存display_start；共享组件按tokens显示 | 正式管理详情接入共享组件，不能直接沿用原文本索引 |
| 管理读取 | 学生登录与本人录音访问不能作为管理跨用户权限 | 列出拟新增的管理读取与音频接口 | 学生组与管理组共同落实服务身份与授权 |
| 覆盖计数 | 命题端recorded接口直接+1；重试、删除恢复未统一 | 统计适配同时输出录音数与独立说话人数；重试按ID去重 | 实现幂等事件或带版本的覆盖快照，不盲目重放+1 |
| 服务端口 | 两组后端默认均用8000 | 联调建议学生8000、命题8001、管理8765、UI预览8790 | 各组配置地址，部署时用同源路由避免冲突 |

命题端公开源码依据：[后端](https://github.com/S-0611/chinese-proposition-subsystem/blob/f978eef098ebd1cfab10da533a054f4d0c81dc45/backend/main.py)、[前端](https://github.com/S-0611/chinese-proposition-subsystem/blob/f978eef098ebd1cfab10da533a054f4d0c81dc45/frontend/app.js)。旧字段约定中仍有`1/(1+rec_count)`，当前后端是`max(0,C-rec_count)`，以当前实现为准；C=10是算法参数，不是老师确认的正式采集目标。

## 请求链路

命题发布题目 → 学生服务调用命题推荐接口 → 学生服务创建练习记录和题目快照 → 上传保留独立录音ID → 学生服务触发诊断 → 管理端授权查询、回听、展示与导出。

算法在线检测直接读取学生服务保存的授权音频，不依赖管理员手工导出。离线算法调试可使用管理导出包。题目覆盖统计可反馈给命题服务，但两端须共用一致口径。

## 现有接口与拟新增接口

| 状态 | 接口 | 用途 |
|---|---|---|
| 命题已有 | `GET /api/questions?level=1&status=published` | 已发布题目列表，返回items |
| 命题已有 | `GET /api/questions/recommend?level=1&n=1` | 返回items数组，学生端取题后建立本地练习关联 |
| 命题已有 | `POST /api/questions/{id}/recorded` | 非幂等+1；不能作为可靠重复补传同步方案 |
| 管理原型已有 | `GET /api/state`、`GET /api/export` | 仅本地演示数据库与演示音频 |
| 管理原型已有 | `POST /api/recordings/update`、`POST /api/undo` | 本地备注、删除恢复、单次撤销 |
| 共同拟定 | `GET /api/v1/admin/recordings` | 跨学生分页查询，必须验证管理员或服务身份 |
| 共同拟定 | `GET /api/v1/admin/recordings/{id}/audio?variant=wav` | 授权音频响应或短效URL，不能暴露磁盘路径 |
| 共同拟定 | `GET /api/v1/admin/recordings/{id}/diagnosis` | 管理身份读取诊断 |
| 共同拟定 | `PUT /api/v1/integration/coverage` | 带snapshot_version的覆盖快照；同版本重放不累加 |

拟定接口尚未部署，路径和认证由所属组确认；不得在演示中标为已接通。共同认证采用何种方式尚未确定，不转发学生登录Cookie冒充管理员。

## 需要双方确认的语义

- 题号保留命题端ID，演示Q编号不能直接映射成真实L1编号；练习ID与录音ID分别保留。
- 录音take_no是练习内序号，不直接当成该学生该题历史全局attempt。唯一性以recording_id为准。
- 每次重录产生新样本；同一上传重试保持同一client_recording_id。需在所属服务保证幂等与所属人校验。
- 统计至少区分有效录音条数和独立说话人数；正式目标未确认时gap为null。有效暂指已保存且未删除，不代表音质合格。
- 诊断失败不等于没有偏误。人工预期答案与机器输出分别保存。
- 真实已知错读样本应覆盖声韵母、声调、增读、漏读及句首句尾边界。当前交接音频仅用于格式联调。
