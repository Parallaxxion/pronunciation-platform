## 三条重点交接链

| 提供方 → 使用方 | 需要交付 | 当前重点 |
|---|---|---|
| 命题端 → 学生端 | 已发布题目、逐字拼音、稳定题号与版本 | 从服务取题并保存题目快照 |
| 学生端 → 管理端 | 授权录音列表、音频、元数据与诊断结果 | 管理角色认证、跨用户权限和偏误索引 |
| 管理端 → 命题端 | 按题覆盖统计、独立说话人数与版本 | 幂等更新，重试、删除、恢复不造成多计 |

统一 UI、算法音频和下载包在[相关材料](../05_相关材料/README.md)。需求认领、阻塞与验收记录在[首页飞书协作入口](../README.md#collaboration)。

修改接口时，在同一 PR 更新字段说明、输入输出示例和受影响测试，列明兼容方案，由相关组共同确认。讨论项写明待确认；正式定稿再更新版本号和生效日期。
