# 前端交接说明

以管理组第一周UI作为三端视觉基准。`baseline/index.html`、`baseline/style.css`、`baseline/app.js`是原文件的完整副本，校验值见baseline.sha256.json。根目录style.css与原CSS完全相同。

## 交接内容

- 原始页面和CSS供查看已有管理布局、表格、弹窗和偏误样式。
- `index.html`和`preview.js`提供独立组件预览，直接读取构造JSON，按统一tokens处理标点和句首句尾增读。
- 全功能原型从管理目录启动，baseline/index.html直接双击不能调用Python后端；不要把API不可用当成样式文件损坏。

从总仓库运行 `python 04_接口说明/联调工具/scripts/preview_ui.py` 后访问localhost:8790。单独下载UI交接包时，在解压后的目录执行 `python -m http.server 8790 --bind 127.0.0.1`，再访问 http://127.0.0.1:8790 。UI预览只展示组件；没有接入登录、麦克风、题库发布和真实管理数据。

## 保持的视觉规则

| 元素 | 基准 |
|---|---|
| 侧栏 | 深青 #102f35，宽224px |
| 页面背景 | #f4f6f4 |
| 主按钮 | 绿色 #246a5b |
| 内容区 | 白色卡片，细边框，圆角 |
| 偏误 | 橙色声调、红色声韵母、蓝色漏读、紫色增读 |
| 页面结构 | 侧栏、标题、提示、统计卡片、表格或详情 |

三组前端共同选一名公共框架维护者，周佳怡提供管理业务需求与原设计检查。学生和命题页面由各组补齐。当前三组均已有原生网页，可先按此基准整合，正式框架选择另行确认；不得仅因为接口使用FastAPI就宣称前端已迁移Vue。

学生页面本期不展示诊断或评分。管理页面的偏误索引必须来自tokens，不能把标点算进字索引。CSS可复用，但接口调用应走各业务适配层，不直接复制演示数据和`/api/state`到所有子系统。
