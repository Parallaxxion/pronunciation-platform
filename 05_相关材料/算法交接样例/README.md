# 算法组格式联调数据包

包含4条正常朗读的合成语音，配套题文、逐字拼音、稳定样例ID、原始文件和标准WAV。用于验证音频读取、拼音输入、ID关联及返回格式。不是人工标注测试集，也不是声韵母检测准确率或训练质量的证据。

## 文件

- `manifest.jsonl`：一行一条样本，含question快照、audio_path、original_path、SHA256、WAV规格和用途。
- `audio/`：16kHz、单声道、16-bit PCM WAV。
- `original/`：第一周原始合成音频，保留原规格。
- `known-errors-template.csv`：后续实录的人工预期结果登记模板，不包含真实测试录音。

所有样本的`gold_errors`为null，表示没有人工真值，不能解读为无偏误。四类偏误的JSON展示样例在总仓库04_接口说明/示例，和本包音频不对应。

## 算法输入与返回

逐行读取manifest，以`question.tokens[].py`作为规范拼音，按audio_path读取WAV；不要把全句拼音重新按词拆开。运行结果使用recording_id关联，保留模型版本。错误类型和位置按公共契约返回；返回原格式也可由适配器转换。

## 下一步共同准备的真实样本

自愿参与的测试人员按题目录制正确朗读，以及明确的声韵母误读、声调误读、漏读、增读；增读覆盖句首和句尾。人工填写题文、实际读音、位置、录音文件和复核人。原始录音与人工真值保存在授权存储中，不提交公开仓库。检测输出单独保存，按录音编号比较。

单靠ASR转写文字再转标准拼音，不能证明保留了实际声调或声韵母偏误；用已知错读实录检查模型能力后再报告准确性。
