# 来源与核验

- [来源与版本](来源与版本.md)：来源范围、日期、作者与公开副本说明。
- [机器可读来源清单](source-snapshots.json)：三组原仓库 commit、当前开发和固定归档位置。
- [导入文件清单](导入文件清单.json)：初始 124 个来源文件的路径、字节数和 SHA256。
- [原核对记录](核对记录.md)：首次整合时完成的检查与未验证范围。
- [目录调整验证记录](目录调整验证记录.md)：本次目录迁移后的导航、工具和保留情况。

校验清单指向固定周次归档；日常代码在“当前开发”继续变化，不要求每次修改业务代码都重写历史来源哈希。后续导入新版本应新增交接记录，保留初始来源证据。
