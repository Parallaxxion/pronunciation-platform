# 第一周验证证据

本目录保存管理端原型的验证记录和演示样例。

| 文件 | 内容 |
|---|---|
| `验证记录.txt` | 现有15项HTTP功能检查与范围说明 |
| `打包复测记录.txt` | 从本次整理后的仓库目录重新运行检查的结果 |
| `演示导出包.zip` | 5条未删除演示样本的音频、信息清单、匿名背景和偏误标注 |
| `录音列表_页面.png` | 第一周录音核查页面截图 |
| `偏误详情_页面.png` | 第一周回听、偏误位置和备注界面截图 |

在仓库根目录运行 `python3 prototype/verify.py`，Windows使用 `py -3 prototype/verify.py`。脚本使用独立临时数据库，不会改动 `prototype/demo.sqlite3`，但会更新验证记录和演示导出包。页面截图来自先前的浏览器检查，重新跑脚本不会重新生成截图或验证浏览器播放。

脚本覆盖版本冲突、删除对统计与导出的影响、撤销保护、音频可读性及清单与标注关联。没有验证真实三端接口、身份认证、HTTPS、负载或算法准确率。

ZIP中的 `manifest.jsonl` 与 `annotations.jsonl` 通过 `recording_id` 关联，音频路径由清单提供。所有背景为虚构数据，音频为合成语音，偏误为人工构造；原始文件和规范WAV在本演示中是同一份音频的不同归档路径。
