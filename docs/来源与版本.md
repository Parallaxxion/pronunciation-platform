# 来源与版本

三个systems目录是完整阶段文件副本，来源提交记录在source-snapshots.json。原仓库历史未合并进本仓库，首次导入时的文件校验清单见evidence/导入文件清单.json。

管理端包含第一周原型、文档、PPT讲稿、证据和成果ZIP，37个文件；学生端包含前后端、诊断代码、一级题库及空值配置模板，27个文件；命题端包含流水线、题库、前后端和报告，60个文件。学生端副本按项目协调人的明确授权公开。

本次新增公共适配器、UI预览、交接包和共同说明。原UI保持三文件逐字节相同，算法交接WAV另存转换后哈希。所有源文件按当前快照保存，不将其他组的既有报告表述成本次实测。

各原作者保留其成果权利；本仓库未替原作者添加新的开源许可证。
