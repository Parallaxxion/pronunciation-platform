# 管理端当前开发

从第一周原型继续开发，代码位于 `prototype/`。历史 PPT、讲稿、需求、分工和验证材料在[第一周归档](../2026.11.09-2026.11.15第1周/README.md)，不在开发目录重复维护。

在总仓库根目录运行：

```bash
python 03_管理端/当前开发/prototype/server.py --open-browser
python 03_管理端/当前开发/prototype/verify.py
```

Windows 可用 `py -3`，macOS/Linux 可用 `python3`。服务默认 <http://127.0.0.1:8765>，按 Ctrl+C 关闭。验证脚本使用独立临时数据库与端口，生成的验证文件位于本目录下 `evidence/`。该运行证据目录和数据库被 Git 忽略；需要留存的结果另复制到当周归档。

管理端成员按分工分别负责页面核查与偏误展示、数据权限与整合、统计导出与校验。共同修改 `server.py` 和 `app.js` 前先约定范围。

公共接口以[接口说明](../../04_接口说明/README.md)为准。真实接口与正式部署仍需接入，原型数据为构造样例。统一提交流程见[总仓库首页](../../README.md)。
