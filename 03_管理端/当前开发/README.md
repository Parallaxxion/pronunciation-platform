# 管理端当前开发

第一周 Web 基准保留在 `prototype/`，本次新增核心管理 API 位于 [backend](backend/README.md)。按 11月23日确认，三组接口齐全后再整合完整 Web。历史 PPT、讲稿、需求、分工和验证材料在[第一周归档](../2026.11.09-2026.11.15第1周/README.md)，不在开发目录重复维护。

在总仓库根目录运行：

```bash
python 03_管理端/当前开发/prototype/server.py --open-browser
python 03_管理端/当前开发/prototype/verify.py
```

Windows 可用 `py -3`，macOS/Linux 可用 `python3`。服务默认 <http://127.0.0.1:8765>，按 Ctrl+C 关闭。验证脚本使用独立临时数据库与端口，生成的验证文件位于本目录下 `evidence/`。该运行证据目录和数据库被 Git 忽略；需要留存的结果另复制到当周归档。

周佳怡负责页面核查与偏误展示；闫晓奕负责数据、权限、撤销和整合；王阳负责统计、导出、校验和部署。新增接口、数据层和认证在 backend 中开发；第一周 app.js 及周佳怡的详情组件留给前端合入，公共接口变化先与受影响成员约定。

公共接口以[接口说明](../../04_接口说明/README.md)为准。管理 API 已具备自身权限和数据管理，已对命题服务做本机 HTTP 联调；学生授权数据和正式部署仍需接入，原型数据为构造样例。统一提交流程见[总仓库首页](../../README.md)。
